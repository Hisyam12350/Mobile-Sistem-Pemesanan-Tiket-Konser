# Mobile-Sistem-Pemesanan-Tiket-Konser

Aplikasi mobile pemesanan tiket konser berbasis [Expo](https://expo.dev) dan React Native.

## Panduan Menjalankan

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Jalankan aplikasi (Development)**
   ```bash
   npx expo start
   ```

3. **Opsi Menjalankan**:
   - Tekan `a` untuk membuka di **Android Emulator**
   - Tekan `i` untuk membuka di **iOS Simulator** (khusus macOS)
   - Scan QR code menggunakan aplikasi **Expo Go** pada perangkat fisik Android/iOS.

## Struktur & Pengembangan
- Kode utama aplikasi berada di dalam direktori `src/app`.
- Proyek ini menggunakan file-based routing dengan Expo Router.
